# Project Proposal

## Title
**House Price Prediction System using Machine Learning**

## Problem Statement
Accurately estimating house prices is challenging due to multiple factors such as location, area, number of bedrooms, amenities, and market conditions. Buyers, sellers, and real estate agencies require a data-driven solution that can predict house prices based on property characteristics to make informed financial decisions.

## Objectives
1. Analyze housing datasets to identify factors affecting house prices.
2. Perform robust data preprocessing and feature engineering.
3. Conduct comprehensive exploratory data analysis (EDA).
4. Build, evaluate, and compare baseline machine learning models for accurate price estimation.
5. Design an overall system architecture for the pipeline.

## Scope
The project focuses on developing a machine learning pipeline starting from data ingestion, preprocessing, EDA, and model training. The initial scope involves evaluating three regression models (Linear Regression, Decision Tree, Random Forest) on the California Housing dataset to establish a performance baseline. This Review-I phase strictly restricts itself to offline, baseline model building, explicitly omitting deployment, MLOps tooling (Docker, MLflow, CI/CD), or APIs.

## SDG Mapping
This project addresses two Sustainable Development Goals:
- **SDG 9: Industry, Innovation and Infrastructure**: Promoting technological advancement in real estate analytics through machine learning.
- **SDG 11: Sustainable Cities and Communities**: Assisting urban planners, buyers, and developers in understanding housing affordability and market trends, ensuring equitable urban development.

## Expected Outcomes
- An insightful Exploratory Data Analysis detailing the factors influencing house pricing.
- Cleaned and preprocessed datasets ready for modeling.
- Trained baseline regression models with performance metrics (MAE, MSE, RMSE, R²).
- High-level architecture diagrams for the machine learning workflow.
